# Science test for EAM potential based on Zhou et al. (2004)


## Pure Cu:

The script test_EAM_ZJW2004.py makes a direct comparison with LAMMPS of thermodynamic output for a liquid of pure Cu, starting with the same configuration. The configuration is generated by the script test_EAM-ZJW-2004-setup.py which creates equivalent configuration files for gamdpy and for LAMMPS : Cu-liquid-rho0.0850-T0.2154.h5 and Cu-liquid-rho0.0850-T0.2154.lammps.

An input file for running the LAMMPS simulation is also included: in.lammps
The file lamms_eam_Cu_ref.dat is taken from the LAMMPS output log, including only the thermodynamics output. The potential file for LAMMPS is not included but can be found here:

https://www.ctcms.nist.gov/potentials/Download/2004--Zhou-X-W-Johnson-R-A-Wadley-H-N-G--Cu/4/Cu_Zhou04.eam.alloy



## Alloys

The script ZJW-2004-EAM-Cu-Au-alloys.py calculates mixing enthalpies for two Cu/Au alloys and compares to literature values for the same potential.
